# Lecture 3

This folder contains the lecture 3 practice code and assignment, starting from page 76 of `lecture3.pdf`.

## Files

- `data/lena.png`: downloaded image resource used by the lecture examples
- `page76_matrix_manipulating.py` to `page82_image_filtering.py`: runnable examples matching the lecture topics
- `page83_assignment.py`: completed solution for the last-page task
- `output/`: generated figures and saved result images

## How to run

Run any script from PyCharm or from the terminal:

```powershell
python page83_assignment.py
```

If you want the Matplotlib window to open as well:

```powershell
python page83_assignment.py --show
```

## Output

- Each script saves a summary figure into `output/`
- The last-page assignment also saves individual result images into `output/page83_assignment/`
